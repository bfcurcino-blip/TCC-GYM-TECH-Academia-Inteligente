# GYM TECH — Sistema Inteligente para Gestão de Academias

## Sobre o projeto

O **GYM TECH** é um sistema web desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas.

A proposta do projeto é oferecer uma plataforma voltada para a gestão de academias, permitindo organizar informações de alunos, profissionais e treinos em um único ambiente.

O sistema busca integrar tecnologia, saúde e bem-estar, proporcionando uma solução digital para auxiliar na administração da academia e no acompanhamento dos alunos.

## Objetivo

Desenvolver um sistema web que facilite a gestão de academias e centralize informações relacionadas aos alunos, equipe e treinos.

O projeto busca proporcionar uma interface organizada e intuitiva, permitindo que diferentes perfis de usuários tenham acesso às funcionalidades relacionadas às suas atividades dentro da academia.

## Funcionalidades implementadas

Atualmente, o sistema conta com diferentes ambientes de acesso e funcionalidades, entre elas:

- Login e autenticação de usuários;
- Diferentes perfis de acesso ao sistema;
- Painel administrativo;
- Painel da recepção;
- Painel do professor/personal;
- Área exclusiva do aluno;
- Cadastro e gerenciamento de alunos;
- Consulta, atualização e remoção de registros;
- Cadastro de informações pessoais e dados físicos dos alunos;
- Registro de peso, altura e objetivo principal;
- Organização dos alunos por modalidade de treino;
- Cadastro e gerenciamento de treinos;
- Visualização dos treinos prescritos pelo aluno;
- Acompanhamento do status dos treinos;
- Opção para marcar treino como concluído;
- Upload de foto do aluno;
- Utilização de hologramas feminino e masculino como imagem de perfil quando o aluno não possui foto;
- Alteração de dados cadastrais pelo aluno;
- Alteração de senha na área do aluno;
- Recurso para visualizar ou ocultar a senha;
- Busca de alunos e treinos;
- Padronização da navegação e dos botões de retorno;
- Integração entre interface, back-end e banco de dados.

## Perfis de acesso

O GYM TECH foi estruturado para atender diferentes tipos de usuários.

### Administrador

Possui acesso às funcionalidades administrativas do sistema, incluindo gerenciamento de alunos, equipe e treinos.

### Recepção

Possui ambiente específico para cadastro e consulta de alunos, além do acesso às informações necessárias para auxiliar no gerenciamento da academia.

### Professor / Personal

Possui área destinada ao acompanhamento dos alunos e gerenciamento dos treinos prescritos.

### Aluno

Possui um portal próprio onde pode:

- Consultar seus dados cadastrais;
- Atualizar informações permitidas;
- Alterar sua senha;
- Visualizar seus treinos prescritos;
- Acompanhar o status dos treinos;
- Marcar treinos como concluídos.

## Personalização do perfil do aluno

O sistema permite utilizar uma foto de perfil para identificação do aluno.

Quando não há uma foto cadastrada, o sistema pode apresentar automaticamente um holograma feminino ou masculino de acordo com a informação registrada no cadastro do aluno.

Essa funcionalidade contribui para a identificação visual dos perfis e para a padronização da interface.

## Interface

A identidade visual do **GYM TECH** utiliza uma proposta moderna e tecnológica, baseada principalmente em uma interface em modo escuro.

A identidade visual utiliza tons escuros combinados com roxo e lilás como cores de destaque, mantendo textos claros para proporcionar contraste e facilitar a leitura.

A interface vem sendo padronizada entre os diferentes ambientes do sistema, buscando manter consistência nos menus, botões, formulários, cards e demais componentes visuais.

## Tecnologias utilizadas

O projeto está sendo desenvolvido utilizando:

- **HTML** — estrutura das páginas;
- **CSS** — estilização e identidade visual;
- **JavaScript** — interatividade e comportamento da interface;
- **PHP** — desenvolvimento do back-end e processamento das funcionalidades;
- **MySQL** — armazenamento e gerenciamento dos dados;
- **SQL** — criação e manipulação das estruturas do banco de dados;
- **XAMPP** — ambiente local utilizado para execução do Apache e MySQL;
- **phpMyAdmin** — gerenciamento e testes do banco de dados;
- **Visual Studio Code** — desenvolvimento e edição do código;
- **Git e GitHub** — versionamento, armazenamento e compartilhamento dos arquivos do projeto.

## Banco de dados

O sistema utiliza um banco de dados MySQL para armazenar as informações necessárias ao funcionamento da aplicação.

Entre os dados gerenciados estão informações relacionadas aos alunos, usuários, treinos e demais registros necessários para o funcionamento dos diferentes ambientes do sistema.

## Funcionalidades em desenvolvimento

O projeto continua em desenvolvimento e algumas funcionalidades ainda estão sendo aperfeiçoadas.

Entre os pontos atualmente em desenvolvimento está o processo de criação automática da senha inicial para novos alunos.

A proposta é permitir que, após o cadastro realizado pela academia, o aluno utilize seu **CPF ou e-mail** juntamente com uma senha inicial para acessar o portal e posteriormente defina sua própria senha na área **Meu Perfil**.

A alteração de senha pelo próprio aluno já está disponível, enquanto o processo de geração automática da senha inicial continua em fase de testes e ajustes.

Outras funcionalidades poderão ser implementadas ou aperfeiçoadas conforme a evolução do projeto.
