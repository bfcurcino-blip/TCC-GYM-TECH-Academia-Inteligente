# 🏋️ GYM TECH — Sistema Inteligente para Gestão de Academias

## 📌 Sobre o projeto

O **GYM TECH** é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas.

A proposta é desenvolver uma plataforma web inteligente voltada para academias, com foco na gestão de alunos, organização de treinos personalizados e acompanhamento do desempenho físico.

O projeto busca unir tecnologia, saúde e bem-estar, oferecendo uma solução digital que possa auxiliar profissionais de Educação Física na organização e no acompanhamento de seus alunos.

## 🎯 Objetivo

Desenvolver um sistema web para auxiliar na gestão de academias e no acompanhamento dos alunos, facilitando a organização das informações, a criação de treinos e o monitoramento da evolução física.

Além da gestão, o projeto busca incentivar a prática de atividades físicas e contribuir para a promoção da saúde e do bem-estar.

## 💻 Funcionalidades previstas

Entre as funcionalidades planejadas para o sistema estão:

- Cadastro e gerenciamento de alunos;
- Organização das informações dos usuários;
- Criação e acompanhamento de treinos personalizados;
- Registro e monitoramento do desempenho físico;
- Gerenciamento das informações da academia;
- Interface simples e intuitiva para utilização do sistema.

> O projeto encontra-se em desenvolvimento e novas funcionalidades poderão ser adicionadas ao longo das próximas etapas.

## 🎨 Interface

A identidade visual do **GYM TECH** está sendo desenvolvida com uma proposta moderna e tecnológica, utilizando uma interface em modo escuro.

A paleta definida para o projeto utiliza:

- **Fundo principal:** preto fosco/cinza grafite (`#121212`);
- **Cor de destaque:** roxo/lilás (`#8A2BE2`);
- **Textos:** branco (`#FFFFFF`).

A proposta visual busca proporcionar boa leitura, organização das informações e uma experiência moderna para o usuário.

## ⚙️ Tecnologias

O projeto está sendo desenvolvido utilizando:

- **HTML** — estrutura das páginas;
- **CSS** — estilização e identidade visual;
- **JavaScript** — interatividade e funcionalidades do sistema;
- **SQL** — estruturação e gerenciamento do banco de dados.
