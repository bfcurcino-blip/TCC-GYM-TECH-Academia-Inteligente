# Sistema Inteligente para Gestão de Academias

## 📌 Descrição
Plataforma web inteligente para academias, focada na gestão de alunos, criação de treinos personalizados e monitoramento do desempenho físico, com impacto na promoção da saúde e bem-estar.

## 🎯 Objetivo
Desenvolver uma solução digital que auxilie profissionais de educação física, otimize a gestão de academias e incentive a prática de atividades físicas.

- HTML  
- CSS  
- JavaScript
